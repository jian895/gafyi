原理

微信只认一个程序，ga 让它变成很多个

微信的 ClawBot 一次只能接一个程序。ga 独占这个会话，按你 @ 的名字把消息分给不同的智能体，再把它们的回复送回来。

你的微信

通过 ClawBot 收发，可以绑定多个微信号，各管各的智能体。

ga

识别 @，路由消息，加解密图片和文件，记住你上次在跟谁说话。

你的智能体

@grokWebhook 推送
@muse链接长轮询
@hermes链接长轮询
@任何能发 HTTP 请求就行

智能体不需要公网 IP。每个智能体有一条专属链接，拿着它就能收消息、发回复。

能做什么

一个对话框，管住所有 AI

@

粘性 @ 切换

@ 一次就记住。之后不带 @ 的消息，继续发给上一个智能体。

⇄

双向通信

智能体可以随时主动找你：定时提醒、任务完成通知，前缀都是它的名字。

▣

图片和文件

收发图片、视频、文件。你发的语音会附带微信的转写文字。

≡

专属接入话术

为 Grok Bot、Muse、OpenClaw、Hermes 写好了接入说明，复制给它就能连上。

◎

多个微信号

一个 ga 可以绑定多个微信，每个微信有自己的一组智能体。

⌂

数据在你手里

部署在你自己的服务器上，消息不经过任何第三方中转，图片按需解密、不落盘。

上手

三步接上第一个智能体

  1. 部署 ga一台有公网 HTTPS 的服务器就够，编译出来是一个文件。
  2. 扫码绑定微信打开后台，点「绑定微信」，用手机扫码，开启 ClawBot。
  3. 新建连接选智能体类型、起个名字，把专属话术发给它。连上后在微信里发「@名字 你好」。
部署 · Linux
# 编译并安装（需要 Go 1.22+）
$ git clone https://github.com/jian895/gafyi.git && cd gafyi
$ make build && sudo install -m 755 gafyi /usr/local/bin/

# 生成后台密钥，写进 /etc/gafyi/config.json
$ gafyi genkey

# 以 systemd 服务运行，然后打开 <public_url>/admin
$ sudo cp deploy/gafyi.service /etc/systemd/system/
$ sudo systemctl enable --now gafyi
名字

为什么叫 ga

ga
Gateway for Agents，智能体网关。中文读「嘎」，消息落地的那一声。
.fyi
for your information，给你捎个信。
@
标志是一个 @。@ 是 ga 唯一的用法，而 @ 的中心本来就是一个 a。外圈不闭合，缺口里的金点是刚送出的那条消息。
